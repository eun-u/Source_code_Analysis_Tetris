# 캠퍼스 RPG 전투·채굴 초안

## 이번 변경 요청

- 한국 대학의 오래된 콘크리트 강의동을 중심으로 대학교·졸업·취업 과정의 공통 색과 배경을 맞춘다.
- 테트리스 블록은 회색 콘크리트 바탕에 미노별 절제된 색을 입힌다. 아이템 광석은 한 칸만 금빛 균열로 표시한다.
- 아이템은 광석 칸이 포함된 줄을 지울 때 채굴한다. 파편이 실제 칸에서 아이템 슬롯까지 이동한다.
- 전투는 학생과 몬스터가 준비·돌진·접촉 타격·피격·복귀하는 근접 공격을 중심으로 보여 준다. 보스 원거리 공격만 별도로 남긴다.
- 기존 3과정·9전투, PvE와 온라인 PvP의 별도 화면 배치와 게임 규칙을 유지한다.

## 구현 범위

광석은 미노의 네 칸 중 한 칸에 귀속된다. 회전·HOLD·상태 직렬화 후에도 귀속 칸이 보존되고, 그 칸이 삭제된 경우에만 획득을 시도한다. 채굴 위치와 슬롯 번호는 전투 이벤트에 담아 시각 효과의 시작점과 도착점으로 쓴다. 슬롯에 들어가지 못한 아이템은 획득 이벤트를 만들지 않는다. 유틸형의 기존 2줄 삭제 즉시 아이템 보너스는 광석 출현 빈도 증가로 바뀌었다.

새 배경 3장, 콘크리트·광석 타일 2장, 학생 및 교수 공격 포즈를 리소스로 포함한다. 리소스의 출처와 용도는 `src/main/resources/ui/campus-rpg/ASSETS.md`에 기록한다. 포즈가 없는 적은 기존 스프라이트와 코드 기반 이동을 사용한다.

## 온라인 전환 경계

로컬 PvE에는 즉시 새 규칙이 적용된다. 온라인 서버도 같은 판정과 채굴 이벤트를 구현했지만, 기존 운영 서버에는 이 변경이 반영되지 않았다. 새 클라이언트가 구 서버에 접속하면 온라인 채굴은 구 서버 규칙으로 판정된다. 새 서버가 보내는 확장 스냅샷과 `EVENTS`는 구 클라이언트가 거부하므로, 운영 배포 전에는 클라이언트 교체 시점·구 버전 차단 또는 버전별 전송 방식을 결정하고 실제 구/신 클라이언트 조합을 검증해야 한다. `render.yaml`의 자동 배포는 꺼져 있으며, 이 브랜치 푸시만으로 운영 서버는 변경되지 않는다.
