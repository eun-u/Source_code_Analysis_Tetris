# 퍼즐 RPG 게임 규칙

상단의 캐릭터와 몬스터 전투는 하단의 테트리스 플레이 결과로 진행한다. HP 소진과 Top-Out을 모두 승리 조건으로 사용한다. 이 문서는 이번 MVP의 규칙 기준이며, 검증 결과는 별도의 실행 로그에 기록한다.

## 기본 전투

- 모든 참가자는 같은 시드의 7-bag 미노 순서로 시작한다. HOLD는 한 미노당 한 번 가능하다.
- 1/2/3/4줄의 HP 피해는 4/8/12/20, 가비지는 0/1/2/4줄이다.
- 첫 연속 클리어는 0콤보다. 0~1/2/3/4 이상 콤보의 추가 피해는 0/4/8/12, 추가 가비지는 0/1/2/3이다. 줄을 지우지 못하면 콤보가 끝난다.
- 일반 HP 피해는 `(기본 피해 + 콤보 보너스) × (1 + 공격 버프 합 - 방어 합)`을 반올림하고 0 이상으로 제한한다. HP 피해는 즉시 적용되며 가비지 상쇄와 독립적이다.
- 퍼펙트 클리어는 고정 피해 40과 가비지 8로 일반 공격을 대체한다. 버프, 방어, 캐릭터 공격 패시브를 적용하지 않고 자동 공격/방어 아이템도 소모하지 않는다. 이후 콤보는 처음부터 시작한다.

## 시간과 가비지

- PvP는 기본형 캐릭터 HP 100, 슬롯 3칸을 강제한다.
- PvP 낙하 간격은 500ms로 시작한다. 60초에 450ms, 이후 30초마다 50ms씩 감소하며 최저 200ms다.
- 가비지는 FIFO 묶음으로 대기한다. 빈 탱크의 첫 수신부터 2초를 기다리며 추가 수신은 대기를 초기화하지 않는다.
- 줄을 지운 착지에서는 먼저 내 대기 가비지를 상쇄하고 차액만 전송한다. 이 착지에서는 가비지가 올라오지 않는다.
- 줄을 지우지 않은 착지에서는 준비된 가비지를 최대 4줄 분출한다. 묶음별 구멍 위치를 유지한다.
- 한 묶음의 구멍은 동일하다. 다음 묶음은 80%로 이전 구멍을 유지하고 20%로 다른 구멍을 고른다. 탱크가 비어도 마지막 구멍을 기억한다.
- 추가 가비지도 모두 상쇄 가능하다. HP 피해는 상쇄하지 않는다.
- 일시정지는 로컬 전투의 게임 시간을 멈춘다. 온라인 시간과 승패는 서버가 결정한다.

## Fever와 캐릭터

- 1/2/3/4줄 클리어는 Fever를 2/5/10/20 충전한다. 100에 도달하면 자동으로 10초 발동한다.
- Fever 중에는 HP 공격 버프 +0.2와 싱글 가비지 1줄이 적용된다. 활성 중에는 충전하지 않는다.
- 이번 클리어로 새로 발동한 Fever와 새로 획득한 공격 아이템은 다음 공격부터 적용한다.
- 공격형: HP 100, 공격 버프 +0.5. 일반 공격으로 2줄 이상 지우면 상쇄 가능한 가비지 1줄 추가.
- 방어형: HP 150. 일반 공격으로 2줄 이상 지우면 상쇄 전에 내 대기 가비지 총량에서 1줄 감소하며 0줄까지 허용.
- 유틸형: 슬롯 4칸. 2줄 이상 지우면 무작위 아이템 1개 획득.
- 캐릭터는 PvE에서만 구매·장착한다. 기본형은 무료다.

## 아이템

- 새 미노 5개마다 아이템 미노 1개를 생성한다. HOLD와 회전으로 아이템이 사라지거나 재추첨되지 않는다.
- 원본 미노의 네 칸 중 어느 한 칸이라도 줄 제거에 포함되면 아이템을 한 번 획득한다. 여러 미노를 함께 지우면 각각 획득한다.
- 같은 아이템도 별도 슬롯을 차지하며 모든 아이템은 1회 사용이다. 정해진 획득 순서로 빈 슬롯을 채우고 초과분만 버린다.
- 사용할 수 없는 상황에서는 아이템을 소모하지 않는다. 지속 효과는 사용 즉시 슬롯에서 소모하고 남은 시간만 별도로 표시한다.
- 자동 아이템은 먼저 획득한 한 개부터 적용한다. 해당 공격/피격에 적용할 수 없는 아이템은 보존한다.

| 아이템 | 효과 |
|---|---|
| 피해 증가 | 다음 일반 공격에 자동으로 공격 버프 +0.5 |
| 가비지 폭탄 | 상대 탱크에 상쇄 가능한 가비지 1줄 |
| HP 회복 | 최대 HP의 10% 회복, 상한 초과 불가 |
| 방어 | 다음 일반 HP 타격에 자동으로 방어율 0.3 |
| 라인 클리너 | 보드의 가장 아래 가비지 행 1줄 제거 |
| Fever 충전 | 게이지 20 충전, 활성 중 사용 불가 |
| 시간 왜곡 | 자신의 낙하 간격을 5초 동안 100ms 늘려 느리게 함, 중복 사용 불가 |
| 무효화 | 상대가 보유한 무작위 아이템 1개 제거 |

## 실행 범위

로컬 무한·Sprint·튜토리얼, PvE 스토리와 캐릭터 구매·진행 저장, 루프백 TCP PvP를 제공한다. 외부 계정 서비스, 공개 인터넷 서버 배포, 랭킹은 이번 게임 규칙 구현 범위에 포함하지 않는다. 화면에 표시하는 전투 값과 결과는 실제 세션 상태에서 읽는다.
