# 임시 픽셀 UI 차용 리소스

이 디렉터리의 PNG 3개는 사용자가 지정한 로컬 프로젝트
`C:\Project\University_Simulation\public\university-survival\png\`에서
2026-10-06에 원본 파일 그대로 복사했다.

- `avatar_player.png`: 전투 화면의 플레이어 초상
- `avatar_professor.png`: 전투 화면의 임시 상대 초상
- `stat_stamina.png`: HP 표시 아이콘

색상과 패널·버튼 표현은 같은 프로젝트의
`src/styles/pixel-design-tokens.css`, `src/styles/global.css`를 참고해
`UniversityPixelTheme`, `PixelArena`, `PixelButton`에 옮겼다.
이 리소스는 현재 UI 검증을 위한 임시 아트다.
